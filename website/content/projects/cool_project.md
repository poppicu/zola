This website is built with Zola and the tabi theme. The layout includes a blog, an archive, tags, and a place to share projects.

The source lives on the [poppicu-website branch](https://github.com/poppicu/zola/tree/poppicu-website). GitHub Actions builds the site and publishes it to GitHub Pages whenever the website changes.
